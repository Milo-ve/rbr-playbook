# Glosario

| Término       | Significa                                                                                                                      |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| RBR           | Release Before Ready: evento de un día donde se construye por la mañana y se presenta demo por la noche                        |
| Giro          | Lo que hace distinta a una edición ("primera edición en la ciudad", "antes de la Tech Week")                                   |
| Community-led | Evento operado por la comunidad local, con menos dependencia del equipo central. Ver [variante](../variantes/community-led.md) |
| Ciudad nueva  | Primera edición en esa ciudad                                                                                                  |
| MC            | Master of Ceremony / host local                                                                                                |
| OOS           | Ops On-Site: operación en la sede                                                                                              |
| Ops Central   | Operación central del equipo RBR                                                                                               |
| Partnerships  | Sponsors y alianzas                                                                                                            |
| RBR admin     | La plataforma de registro, pitches y votos. Hoy se exporta por CSV                                                             |
| Cortesía      | Boleto sin pago                                                                                                                |
| Perk          | Beneficio de un sponsor para los participantes                                                                                 |
| Media kit     | Material para que el sponsor comparta en sus redes                                                                             |
| En especie    | Aporte sin dinero (por ejemplo, el venue). Monto 0                                                                             |
| Break even    | Lo que se necesita de sponsors para no perder: costos − tickets netos                                                          |
| TC            | Tipo de cambio, del día del evento                                                                                             |
| Dev Racing    | Reto de construcción de la tarde, con demos                                                                                    |
| Morning deck  | Presentación de bienvenida del MC                                                                                              |
| 500 Latam     | Cuenta de la comunidad. Nunca "500 Global"                                                                                     |
| T###          | Id de una plantilla de tarea (ver `_playbook/pilares/*/tareas.md`)                                                             |
| Fase          | `pre`, `dia` o `post` respecto al evento                                                                                       |
